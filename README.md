# Vendor Site Wizard для 1С-Битрикс

## Что реализовано
- Мастер с шагами проверки окружения, выбора структуры, региональности и создания инфраструктуры.
- Автосоздание инфоблоков `catalog`, `blog`, `news` с базовыми свойствами.
- Генерация демо-данных (разделы каталога, товары, посты, новости).
- Копирование публичных страниц (`/catalog/`, `/blog/`, `/news/`, `/personal/cart/`, `/personal/order/make/`, `/about/`, `/contacts/`).
- Добавление меню, правил `urlrewrite`, мультисайтовых записей и свойства заказа `REGION`.

## Путь мастера
`/bitrix/modules/vendor.sitewizard/install/wizards/vendor/site/`

## Важные замечания
1. Это инженерный каркас под ваше ТЗ: для production стоит добавить:
   - строгий rollback;
   - замену плейсхолдеров `#CATALOG_IBLOCK_ID#`, `#BLOG_IBLOCK_ID#`, `#NEWS_IBLOCK_ID#` в скопированных файлах;
   - расширенные проверки редакций Битрикс (`Старт`, `Стандарт`, `Бизнес`) и модулей;
   - полноценную модель региональных цен/складов и обработку смены региона в UI.
2. Для повторного запуска мастер проверяет существование инфоблоков и элементов по коду, чтобы не дублировать базовые сущности.

## Быстрый запуск
1. Установите модуль `vendor.sitewizard`.
2. Запустите мастер установки решения в административной панели.
3. Пройдите шаги и укажите домены/валюту/язык.
