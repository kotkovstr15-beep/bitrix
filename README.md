# Vendor Site Wizard для 1С-Битрикс

## Как установить модуль (пошагово)

### Вариант 1: локально из файловой системы
1. Скопируйте папку модуля в каталог проекта:
   - источник: `bitrix/modules/vendor.sitewizard/`
   - назначение: `<ваш_проект>/bitrix/modules/vendor.sitewizard/`
2. В админке Битрикс откройте:
   `Marketplace -> Установленные решения -> Модули`.
3. Найдите модуль `vendor.sitewizard` и нажмите **Установить**.
4. После установки откройте мастер в разделе:
   `Настройки -> Настройки продукта -> Список мастеров`.
5. Запустите мастер `vendor:site` и пройдите шаги.

### Вариант 2: через консоль (если доступна)
```bash
php -f bitrix/modules/main/tools/cli.php -- module install vendor.sitewizard
```

> Если CLI-обвязка в проекте не подключена, используйте установку через админку (Вариант 1).

## Что делает установка модуля
- Регистрирует модуль `vendor.sitewizard`.
- Копирует wizard из `install/wizards/` в `/bitrix/wizards/vendor/site/`.
- После этого мастер появляется в списке мастеров.

## Что делает wizard
- Проверяет окружение (версия ядра, модули, права на запись).
- Создает инфоблоки `catalog`, `blog`, `news` и свойства.
- Заполняет демо-данными.
- Копирует публичные страницы: `/catalog/`, `/blog/`, `/news/`, `/personal/cart/`, `/personal/order/make/`, `/about/`, `/contacts/`.
- Добавляет базовое меню, urlrewrite-правила, сайты по доменам и свойство заказа `REGION`.

## Важно перед продом
- Добавить полноценный rollback.
- Добавить подстановку `#CATALOG_IBLOCK_ID#`, `#BLOG_IBLOCK_ID#`, `#NEWS_IBLOCK_ID#` в скопированных страницах.
- Детализировать региональные цены/склады под вашу бизнес-логику.
